# Моё СНТ

Приложение для Android с планом СНТ «Дружба» (Щербинка, квартал 134).

- План участков по кадастровым границам из проекта электросетей, две дороги, разделённые участки 1, 3, 34, 47.
- Нажатие на участок открывает карточку: ФИО, телефон, присоединённый объект, адрес, кадастровый номер. Кнопки «Скопировать», «Позвонить», «WhatsApp».
- «Изменить сведения» правит карточку; правки хранятся в памяти телефона (`files/plots.json`). Кнопки «Сохранить копию данных» и «Восстановить из копии» внизу экрана.
- Долги за текущий год при каждом запуске берутся из первой вкладки Google-таблицы «Взносы СНТ» (таблица должна быть открыта по ссылке для чтения). Должники подсвечены красным.

## Сборка

Android SDK не нужен, хватит JDK, Python 3 и curl/git (как в проекте Tuner):

```
./build.sh          # → build/MoeSNT.apk
```

`fetch-tools.sh` при первом запуске скачает `android.jar` (API 29) и `dx`. APK подписывается ключом `snt.keystore`, он лежит в репозитории, чтобы обновления ставились поверх установленного приложения.

Страница плана — `assets/index.html` (один файл: SVG, стили, скрипт). Нативная часть — `src/ru/andrey/snt/`.
